Интерактивная панель управления личными финансами, созданная с использованием HTML, CSS и JavaScript.

# Возможности

1.Отображение общего баланса, доходов и расходов.

2.График финансовой активности по месяцам.

3.Список транзакций с датами, категориями и суммами.

4.Добавление новых доходов и расходов.

5.Поиск и фильтрация транзакций.

6.Удаление транзакций.

7.Сохранение данных в `localStorage`.

8.Экспорт транзакций в CSV.

9.Адаптивный интерфейс для мобильных устройств.

# Технологии
- HTML5
- CSS3
- JavaScript
- SVG для графиков
- LocalStorage API

# Запуск проекта
1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта.
3. Запустите `index.html` в браузере.

(Для удобной разработки рекомендую использовать расширение Live Server в Visual Studio Code.)

# Хранение данных
Транзакции сохраняются в локальном хранилище браузера (`localStorage`). Поэтому данные остаются после перезагрузки страницы, но не синхронизируются между разными браузерами или устройствами
